# Public Assets

## Video Files

The demo video player expects a video file at `/demo-forensics.mp4`. 

**Current Status**: The demo video file is missing, so the video player shows a placeholder.

**To add a demo video**:
1. Place an MP4 video file named `demo-forensics.mp4` in this directory
2. Optionally add captions file `demo-forensics-captions.vtt`

**Video Requirements**:
- Format: MP4
- Recommended aspect ratio: 16:9
- Recommended duration: 10-30 seconds
- Content: Any sample video for demonstration purposes

The video player includes error handling and will show a placeholder if the video file is not available.
